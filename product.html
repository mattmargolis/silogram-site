Live numbers, tracked changes

Writers, co-authors and agents work in one draft. When the analysis changes and the document syncs, linked numbers update and Silogram shows what moved; the number audit finds numbers typed by hand.

  • Word export with real tracked changes
  • Import a co-author's edits as suggestions

Your house style, learned from past papers

Upload past manuscripts and abstracts. Silogram learns spelling, voice, how you write P values and CIs, preferred terms and abbreviations.

Security and compliance

New · Reproduce from code

Proof that the code produces the numbers.

A runner re-runs your analysis at a commit, in a container with no network access, and Silogram checks that it produces every value, table and figure your documents cite.

  • Your runner sits inside your network, next to the data; only the declared outputs and a status line come back
  • Pin it to your own repository and it runs only committed code with the committed command
  • Or use Silogram's hosted sandbox for synthetic or de-identified data
  • Read-only data, no network, no privileges, time and memory limits
  • Each run, its log and the comparison are in the audit trail
